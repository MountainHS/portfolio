## 공통 규칙

- 절차 전체는 스킬 `/tech-doc-issue-summary`에 있습니다. 발췌 검사: `python .claude/skills/tech-doc-issue-summary/scripts/check_quotes.py <분류 파일> <P>-alias.tsv`. 상태 숫자: `python .claude/skills/tech-doc-issue-summary/scripts/gomin_status.py <분류 파일>`.
- ID는 프로젝트 접두어를 붙입니다: `<P>-D-001`. 한 번 붙인 ID는 바꾸지 않습니다.
- 원천에 근거가 없거나 애매한 칸은 `🟡 구체화 필요 (Q-번호)`, 사용자가 미룬 칸은 `⏸ 보류 (Q-번호)`. 질문은 각 파일 §1 고민 상자 안에 둡니다.
- 참고 범위 문서에 형식 칸에 맞는 내용이 있으면 먼저 채우고(추론·출처 표시) 질문합니다.
- L1 고민의 질문은 면접 대비 취약점 목록(V-번호)으로 옮깁니다.
- 사용자 답은 새 출처입니다. 원천·기술 문서와 어긋나면 양쪽을 남기고 "충돌"로 표시합니다.
- 정확한 일자는 기술 문서에 쓰지 않습니다(분류 파일에는 남겨도 됨).
- 조사 범위는 사용자가 고른 원천 폴더와 각 프로젝트 문서뿐입니다. Git 이력·코드·블로그는 허락 뒤에만 봅니다.
