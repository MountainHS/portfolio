# 분류 → 기술 문서 반영

출처: 세션 "WGO 고민 분류를 기술 문서에 반영하고 빌드"(2026-11-16)와 커밋 `a06ef2c`의 `src/4-wgo/기술문서.md` 변경. 사용자가 "기술 문서에 반영해 줘"라고 했을 때만 합니다(루트 `CLAUDE.md` 원칙 2의 "고쳐 줘").

## 근거 규칙

- 근거는 분류 파일의 사용자 답(💬 줄·대응표 `사용자 답` 행)과 원천 발췌뿐입니다. 새 사실·수치·의도는 만들지 않습니다.
- `(추론)`·`(추정)`이 붙은 내용은 기술 문서에 사실로 쓰지 않습니다. 쓰고 싶으면 report 「확인해 주세요」에 남깁니다.
- ⏸ 보류 고민은 답이 없는 부분을 비워 둡니다. V-취약점은 넣지 않습니다(답변 준비용).
- 원천과 기술 문서가 충돌하면 분류 파일의 결론을 따릅니다. 결론이 없으면 고치지 않고 report에 적습니다.
- 고민과 무관한 줄은 고치지 않습니다. 사용자가 직접 고친 줄은 먼저 `git diff`로 찾아 글자 그대로 둡니다.
- 기술 문서 본문에 넣지 않는 것: 정확한 일자(상대 시점 "1차 빌드", "마지막 스프린트"로), 커밋 해시·메시지, `(§4.4)`·`파일:줄`·`R2:L92`·`Q-49` 같은 출처. 근거는 report의 반영 목록 "근거" 열에만. 문서 안 상호 참조 `(6.3-1)`은 원래 꼴이면 유지하고 번호가 밀리면 맞춥니다.
- 문체는 지금 기술 문서를 따릅니다(WGO는 "~다" 평서체). `.claude/CLAUDE.md` 「글쓰기 기본 지침」(핵심 먼저, "A가 아니라 B" 금지, 목적 절에 구현 금지)과 `.claude/rules/portfolio-writing.md`를 지킵니다.

## Level별 자리와 꼴

| 분류 | 자리 | 꼴 |
|---|---|---|
| L3 | 고민과 선택 절(§5) | 대안 비교 표(있으면 행만 고침) → **최종 결정** → 결정자·대안별 판단 목록 → 시행착오 굵은 소제목 단락(예: **프로젝트 안에서는 2단계까지**) → 회고(**다시 고른다면: …**) |
| L2 트러블슈팅 묶음 | 결과와 회고 절 아래 새 상위 절 | 상위 절 첫 문장 = 회고 원문 기준 교훈. 핵심 사례는 **문제 → 원인 → 해결(1차·2차) → 배운 점**, 자잘한 사례는 굵은 라벨 목록으로 둘씩 |
| L2 기존 비교 절 | 그 절 그대로 | 결과 문장만 바꿈. 결론이 바뀌면 "문서를 쓰며 떠오른 방안" 소제목으로 |
| L2 구현의 계기 | 구현 절(§4.x)·기획 의도 | "이 리팩토링을 시작한 계기는 두 가지다." + 목록, 또는 이름 없는 단락 |
| L2 결과 한 줄 | 결과 절 | 문장 하나 |
| L1 | 해당 구현 절 | 1~3줄 보충. 원인 모를 버그는 "원인은 끝내 찾지 못했다. 그래서 … 예방했다" |
| L1 미해결·기록 소실 | 아쉬운 점(기술 부채) | 한 문장으로 합침 |
| TD에 아예 없던 L1·협업 묶음 | 넣지 않음 | report에 "넣지 않은 후보(원하면 말해 주세요)" |
| AI가 해결 과정에 쓰인 고민 | 규칙 6의 6단계 | 프롬프트·AI 결과 원문이 없으면 쓰지 않고 report에 빠진 단계 적기 |

## 순서

1. 규칙 파일·분류 파일(§1·§6·§8)·대화 파일·`INDEX.md`를 읽고, `git diff`로 사용자가 고친 줄을 찾습니다.
2. 기술 문서를 앞쪽 절부터 고칩니다. 절을 옮기면 번호와 본문 상호 참조를 함께 맞춥니다.
3. 사용자가 고친 줄이 그대로인지 grep으로 확인합니다.
4. `/portfolio-build <폴더>` → `deck-edits.py apply --all` → `python .claude/skills/portfolio-build/portfolio-edits.py apply --all`.
5. `/portfolio-edit`로 고정(pin)한 장면이 바뀐 내용과 맞지 않으면 되돌리기를 권하고, 사용자 승인 뒤에만 합니다.
6. 편집 서버로 세 페이지를 점검합니다(빨간 띠·식별자 끊김, `.claude/rules/portfolio-writing.md` 「렌더 검수 방법」).
7. `report/<폴더>.md` 맨 위 "이제 할 일"에: 반영 목록(고민 ID · TD 절 · 근거 `별칭:L줄`·Q-번호), 비운 곳(보류·추론이라 뺀 것), 「확인해 주세요」(사용자 답을 Claude가 문장으로 옮긴 곳), 촬영 요청(§8 사진 목록). 루트 `report.md`는 요약판으로 다시 씁니다.
8. 커밋하지 않습니다(요청 때만).
