# 소개 영상 자막 퇴고

> 언제: 자막을 쓰거나 고친 **직후, 렌더 전**에 매번 돌립니다. 작업·세션 끝으로 미루지 않습니다(자막 수정 → 검사기 → 퇴고 → 렌더). 자막을 쓰는 동안 미리 읽을 필요는 없습니다.
> 근거: 2026-11-21 사용자 피드백(소개 영상 자막 지침)을 퇴고 절차로 줄인 것입니다. 원문 파일은 사용자 결정으로 지웠고, 이 스킬이 기준입니다.
> 하위 에이전트가 자막을 썼으면, 메인 세션이 돌아온 결과에 이 절차를 돌립니다.

## 기준: 영상의 역할

- 소개 영상은 **기술문서의 요약본이 아닙니다.** 기술문서를 읽기 전에 게임이 무엇이고 어떻게 플레이하는지 보여 주는 도입 자료입니다.
- 주 시청자는 **채용 담당자·게임 기획자·비개발 직군**입니다. 기술 면접관은 부 시청자입니다.
- 자막이 전할 것: 게임 정체성·목표 → 핵심 경험 → 기본 루프 → 화면에 보이는 게임 특징(몬스터 위협, 대응, 강화, 보스, 승리).

## 퇴고 절차

1. **검사기를 돌립니다.**
   ```bash
   python video/check_subtitles.py <hive|wgo>            # 정본
   python video/check_subtitles.py <hive|wgo> <초안.tsv>  # 다른 파일
   ```
   콘솔 한글이 깨지면 `PYTHONIOENCODING=utf-8`을 붙입니다. 오류 0이 될 때까지 고칩니다. 경고는 줄마다 고치거나, 남기는 이유를 결과에 적습니다.
2. **줄마다 아래 「줄 점검」을 봅니다.** 검사기는 단어·길이·시각만 봅니다. 나머지는 직접 판단합니다.
3. **`from` 칸을 판정합니다.**
   - `확인함` — 사용자가 영상에서 확인한 문장(사용자가 말하기 전에는 쓰지 않음)
   - `소개용 새 초안` — 게임 규칙·루프처럼 화면 확인이 필요 없는 문장
   - `화면 확인 필요` — 효과·동작이 보이는지 모르는 문장(= 지침의 "조건부 적합")
   - `자막 생략` — `text`를 비운 줄
4. **두 산출물로 냅니다.**
   - 전체 자막: `<proj>-subtitles.tsv` (`cut start end text doc from`, 탭 구분, 시각은 원본 영상 기준)
   - 화면 확인 목록: `<proj>-subtitles-review.tsv` (`cut source_start source_end status draft_text check_in_video fallback_if_not_visible`). `화면 확인 필요` 줄은 모두 여기에도 올립니다.
5. **「끝내기 전 점검」을 통과하면 결과를 알립니다.** 검사 결과 숫자와 남긴 경고를 함께 적습니다.

## 줄 점검

- 이 줄이 기여하는 것이 정체성 / 루프 / 핵심 경험 / 화면의 게임 특징 중 하나인가? 아니면 자막을 비웁니다.
- 화면만으로 이해되는 장면인가? 그러면 자막을 비웁니다. 컷마다 한 문장을 채울 의무는 없습니다.
- 컷 메모에 적힌 사실인가, 내 추측인가? 영상을 직접 보지 않았으면 효과·UI·동작은 모두 `화면 확인 필요`입니다.
- 기술 용어를 쉬운 말로 바꾸기 **전에**, 이 문장이 필요한가? 내부 구현 설명이면 문장째 지웁니다.
- 개발 의도("~하게 했습니다")가 아니라 플레이어가 겪는 일("~해야 합니다", "~가 나타납니다")인가?
- 팀원이 만든 장면(무기·보스·UI)을 내 구현처럼 쓰지 않았나? 담당 구분은 기술문서의 몫입니다.
- `doc` 칸은 참고용입니다. 기술문서 절에 맞추려고 문장을 고르지 않습니다.

## 2026-11-21에 실제로 한 실수 (같은 것이 있으면 고침)

| 실수 | 예 | 바로잡는 법 |
|---|---|---|
| 기술문서 목차를 영상에 맞춤 | 컷마다 §3.3·§3.7 문장을 붙임 | 컷마다 "이 장면이 게임의 무엇을 보여 주나"부터 정함 |
| 화면에 안 보이는 구현 설명 | `표(TSV) 데이터로 … 재사용합니다` | 문장째 삭제. 보이는 결과만 씀 |
| 기술 용어를 쉬운 말로만 바꿈 | `상태 머신` → `행동을 관리하는 시스템` | 바꾸기 전에 그 문장이 필요한지 먼저 판단 |
| 영문·구현 키워드 | `Flash로 강조`, `Windup`, `WorldItemId` | `순간적으로 빛납니다`처럼 보이는 현상만 |
| 화면 미확인 내용을 단정 | 약점 발광이 실제로 보이는지 모름 | `화면 확인 필요`로 표시하고 확인 목록에 올림 |
| 모든 컷에 자막 | 전투 장면마다 설명 | 화면만으로 이해되면 자막 생략 |
| 내 담당을 영상에서 주장 | `내 담당은 몬스터 전체입니다` | 영상에서 빼고, 팀원 구현을 내 것처럼 쓰지 않음 |

## 검사기 참고

- `video/check_subtitles.py` — `render.py`도 렌더 전에 부르고, 오류가 있으면 렌더를 멈춥니다.
- 금지어·주의어·허용 영문은 `video/subtitle-words.tsv`(사용자가 고치는 표). 기준값(32자·초당 10자·1.5초)은 스크립트 맨 위.
- 오류: 영문(허용 목록 밖), 금지어, 컷 표에 없는 cut, 컷 밖 시각. 경고: 주의어, 화살표 문장, 길이·읽기 속도·표시 시간, review 파일에 없는 `화면 확인 필요` 줄.

## 끝내기 전 점검

- [ ] 비개발자가 기술문서 없이 이해하는가?
- [ ] 장르·목표·전투→강화 루프가 드러나는가?
- [ ] 화면에서 확인 못 한 내용을 단정하지 않았는가?
- [ ] 자막 없이 이해되는 장면은 비웠는가?
- [ ] 팀원이 만든 장면을 내 구현처럼 쓰지 않았는가?
- [ ] 검사기 오류 0인가?
- [ ] 전체 자막과 화면 확인 목록(review)을 나눠 냈는가?
