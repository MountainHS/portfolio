# 쇼츠 컷·자막 규칙 (이 포크 전용)

> 2026-11-24 사용자 지시에서 옮겼습니다(2026-11-26 메모리 정리). **소개 영상(긴 버전)과 규칙이 다릅니다.** 소개 영상은 기술·"내 담당"을 넣지 않지만(`/video-subtitle-revise` 스킬), 쇼츠는 뒷부분에 기술과 내가 한 일을 넣습니다.

## 컷 순서

1. **게임 루프 단계** — 원 영상의 루프 단계를 빠짐없이, 원래 순서대로 보여 줍니다. 시간이 없으므로 핵심 루프 단계만 남기고, 세부 루프(탐색·접근·제압 등)는 한 장면으로 합칩니다.
2. **볼만한 클립** — 시각적으로 볼만한 장면.
3. **내 담당** — 기술·담당 설명은 핵심 한두 줄만. 화면에 보이는 것은 짧게 붙여도 됩니다(예: 돌진·독안개·도약 몬스터 이름과 동작).
4. **마무리 글귀** — 따로 둔 짧은 컷, 게임 이름으로 끝맺습니다.

## 자막

- 기술 자막은 프로젝트 문서에 있는 사실만 씁니다.
- 화면에 잘 드러나지 않는 기술은 최소화합니다.
- 부가 정보는 최대한 줄입니다. 인공지능 협업·테스트 인원처럼 화면에 없는 사실은 프로젝트 문서에 맡기고 쇼츠 자막에서 뺍니다.

## 실제 사례 (2026-11-24 Hive Purge 첫 쇼츠, `video/hive-short-*.tsv`)

- **틀린 것:** 첫 쇼츠가 소개 영상 규칙을 그대로 따라 기술·담당을 모두 뺐고, 루프 단계 순서도 섞었습니다. 사용자가 다시 검토하라고 했습니다.
- **고친 방향:** 루프 단계를 원래 순서로 먼저 → 볼만한 클립 → 돌진·독안개·도약 몬스터 담당 장면 → 게임 이름 마무리 컷.
