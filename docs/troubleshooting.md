# 문제 해결

## 만들기 · 미리보기

| 증상 | 원인과 해결 |
|---|---|
| 파일을 더블클릭하면 빈 화면 | 로컬 서버로 열어야 합니다 → [미리보기](tools/build.md#미리보기) |
| `/portfolio-…` 명령이 목록에 없음 | 이 레포 폴더를 열고 Claude Code를 시작했는지 확인하세요. 방금 받은 명령이면 Claude Code를 새로 시작합니다. 방법 B로 만들었다면 숨김 폴더 `.claude/`가 복사됐는지 확인하세요. 옛 템플릿이면 [템플릿 업데이트 받기](tools/update.md#템플릿-업데이트-받기) |
| "Python이 없습니다" | Windows에서는 `python` 대신 `py`를 써 보세요. 둘 다 없으면 [Python](https://www.python.org/downloads/) 3.8 이상을 설치(**Add python.exe to PATH** 체크)한 뒤 Claude Code를 다시 시작합니다. 장면 고치기는 Python 없이 동작하지 않습니다 |
| README의 `docs/…` 링크가 열리지 않음 · `docs/` 폴더가 없음 | 예전 `/portfolio-update`로 받은 레포입니다(예전 명령은 `docs/`를 받지 않음). `/portfolio-update`를 한 번 더 입력하세요 → [`docs/` 폴더가 없다면](tools/update.md#docs-폴더가-없다면) |
| `/portfolio-update`가 "템플릿이 아닌 곳에서 받게 됩니다"라며 멈춤 | 이 PC의 git 설정(`url.….insteadOf`)이 템플릿 주소를 다른 곳으로 바꾸고 있습니다. 일부러 넣은 설정인지 확인하거나 강사에게 문의하세요 → [더 알아 둘 것](tools/update.md#더-알아-둘-것) |
| `/portfolio-build`가 내 프로젝트를 건너뜀 | 폴더 바로 아래에 `.md` 프로젝트 문서가 있는지 확인하세요. `_intake/`(재료집·발표자료)만 있으면 "아직 재료집 단계"로 건너뜁니다 |
| 고친 것이 안 보임 | **Ctrl+F5**. 배포는 반영까지 1~2분(최대 10분) 걸립니다 |

## 배포

| 증상 | 원인과 해결 |
|---|---|
| 배포 주소가 404 | [format/06-deploy.md](../format/06-deploy.md) |
| 이미지가 안 보임 (특히 배포 후에만) | 파일 이름 **대소문자**와 상대경로(`images/…`)를 확인하세요. Windows 미리보기에서는 열려도 Pages에서는 깨질 수 있습니다. `report.md`에 고칠 방법이 적힙니다 |
| 프로젝트가 페이지에 안 보임 | `data/`를 commit · push했는지, `profile.md`의 프로젝트 순서에 적은 폴더 이름이 대소문자까지 맞는지 확인하세요 |

## 슬라이드

| 증상 | 원인과 해결 |
|---|---|
| 장면 아래에 빨간 **내용이 잘렸습니다** 띠 | 글자를 하한(본문 14px)까지 줄여도 그 장면에 다 들어가지 않은 것입니다. 배포된 페이지와 PDF에도 보이니 꼭 고치세요. 프로젝트 문서에서 그 부분을 줄이고 다시 빌드하거나, `/portfolio-edit`로 그 장면에 넣는 글·그림을 줄이거나 둘로 나눕니다. 띠의 `원문:` 뒤 주소가 잘린 장면입니다 |
| 그림 자리에 빨간 **원문에서 찾지 못했습니다** / **원문 위치가 여러 곳입니다** / **원문이 바뀌었습니다** 띠 | `data/`가 가리키는 그림·코드·표를 지금의 프로젝트 문서에서 찾지 못한 것입니다(프로젝트 문서를 고친 뒤 다시 빌드하지 않았을 때 흔함) → `/portfolio-build`. 띠에 "고친 장면입니다"라고 나오면 `/portfolio-edit`로 그 장면의 그림을 다시 고르거나 되돌리세요. "다이어그램을 그리지 못했습니다"는 프로젝트 문서의 mermaid **문법 오류**입니다 |
| 아래에 노란 **예전 데이터로 자동 구성** 띠 | `data/`가 예전 방식이라 임시로 꾸린 슬라이드입니다(템플릿 업데이트 직후에 흔함) → `/portfolio-build` |
| 아래 띠 오른쪽에 빨간 숫자 | 미리보기에서만 보이는 장면 배치 점검 결과입니다(배포·PDF에는 안 나옴). Claude에게 "미리보기 배치 점검 결과 알려 줘" |
| 고친 슬라이드 장면이 원래대로 돌아감 | 그 장면의 프로젝트 문서 절 제목을 바꾸면 풀립니다. `/portfolio-edit`로 다시 고치세요 |

## PPTX · 문구

| 증상 | 원인과 해결 |
|---|---|
| PPTX를 열었더니 글자 모양·줄바꿈이 화면과 다름 | 그 PC에 Pretendard · D2Coding 글꼴이 없어서 PowerPoint가 다른 글꼴로 보여 주는 것입니다. 글꼴을 설치하거나 **[홈 → 바꾸기 → 글꼴 바꾸기]** → [슬라이드를 PPTX로 저장하기](tools/export.md#슬라이드를-pptx로-저장하기) |
| [PPTX로 저장]을 눌렀는데 "PPTX를 만들지 못했습니다" | 처음 한 번은 변환 도구를 인터넷에서 받습니다. 연결을 확인하고 다시 누르세요. 그래도 안 되면 Claude에게 "PPTX 저장이 안 돼"라고 알려 주세요 |
| 문구 표를 고쳤는데 그대로·이상함 | 칸 사이가 탭이 아니라 공백이면 그 줄은 기본 문구로 나옵니다 → "문구 표 점검해 줘" |
