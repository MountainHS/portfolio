# 내보내기 — 배포 · PDF · PPTX

## 배포하기

| | |
|---|---|
| **방법** | commit · push 뒤 GitHub Pages(`main` 브랜치의 `(root)`) |
| **언제 쓰나** | 미리보기로 확인을 마친 뒤 |
| **바뀌는 것** | 배포된 페이지 — push한 내용이 그대로 보입니다 |
| **되돌리기** | 문서를 고치고 다시 빌드 · commit · push하면 바뀐 내용으로 다시 배포됩니다 |

**커밋할 것과 안 할 것**

| commit · push해야 배포에 보이는 것 | 내 PC에만 남는 것 (자동으로 git 제외) |
|---|---|
| `src/`(프로젝트 문서·images·code·`deck-edits.json`), `profile.md`, `data/`, `theme/theme.css`, `theme/strings.tsv`, `theme/layout.json`·`custom/`(만들었다면) | `report.md`, `report-intake.md`, `src/*/_intake/` |

> Claude는 push하지 않습니다. 미리보기로 확인한 뒤 **여러분이 직접** commit · push하세요.

**GitHub Pages**

GitHub Pages는 **`main` 브랜치의 `(root)`** 로 배포합니다. 레포가 공개(Public)여야 무료 플랜에서 동작합니다. 주소는 `https://<아이디>.github.io/<레포>/` 입니다. 자세한 내용과 문제 해결은 [format/06-deploy.md](../../format/06-deploy.md).
배포 직후에는 브라우저가 예전 화면을 보여 줄 수 있습니다. 최대 10분 기다리거나 **Ctrl+F5**로 새로 고치세요.

## PDF로 제출하기

| | |
|---|---|
| **방법** | 배포된 주소에서 머리 막대의 **[PDF로 저장]** 버튼 |
| **언제 쓰나** | 지원서에 링크와 함께 PDF 사본을 낼 때 |
| **바뀌는 것** | 저장한 PDF 파일 (레포는 바뀌지 않습니다) |
| **되돌리기** | 다시 저장하면 됩니다 |

기업 보안 정책상 외부 링크가 막힌 곳도 있으니 **링크와 함께 PDF 사본**도 준비하세요.
**Windows PC의 Chrome 또는 Edge**에서 저장합니다. Mac, 휴대폰·태블릿, Safari·Firefox는 지원 범위 밖입니다.

1. **배포된 주소**(`https://<아이디>.github.io/<레포>/`)에서 포트폴리오 페이지를 엽니다. 미리보기(로컬 서버)에서 저장한 PDF는 링크가 내 컴퓨터 주소를 가리키니, 제출용은 꼭 배포된 주소에서 저장하세요.
2. 머리 막대의 **[PDF로 저장] 버튼**을 누릅니다. 아래쪽 그림까지 받은 뒤 인쇄 창이 열립니다(`Ctrl+P`도 되지만, 아직 받지 않은 그림이 빠질 수 있어 버튼을 권합니다).
3. **대상**을 **PDF로 저장**으로 고릅니다. 용지는 **A4**, **여백은 "기본"** 그대로 둡니다. 머리글과 바닥글(날짜·주소)은 끕니다.
4. 머리·자기소개·기술 스택이 맨 앞(기술이 많으면 2쪽까지), 프로젝트마다 **소개와 기능 소개가 각각 새 쪽에서 시작**, 한눈에 보기·연락처가 맨 끝입니다. 버튼과 머리 막대는 인쇄되지 않고, 링크는 **칠 수 있는 주소 글자**로 나옵니다(PDF에서는 눌러도 열림).

**제출 기본은 포트폴리오 페이지(`index.html`) PDF 한 파일**입니다.

### 슬라이드·상세 문서 PDF와 그 밖의 주의

- 슬라이드(`project.html?p=…`)는 아래 띠의 <b>[PDF로 저장]</b>으로 프로젝트별 16:9 PDF가 됩니다(장면 1개 = PDF 1쪽, 여백 기본, Edge는 시트당 페이지 수 1). 미리보기의 쪽 수가 버튼에 적힌 쪽 수와 같으면 저장하세요. 특정 프로젝트의 발표 자료가 따로 필요할 때 씁니다.
- 슬라이드는 <b>[PPTX로 저장]</b>으로 PowerPoint 파일도 만들 수 있습니다. 발표 자료를 직접 다듬을 때 쓰고, 제출은 PDF가 기본입니다 → [슬라이드를 PPTX로 저장하기](#슬라이드를-pptx로-저장하기)
- 프로젝트 상세 문서(`doc.html`)도 `Ctrl+P`로 A4 문서처럼 인쇄할 수 있습니다. 코드·그림이 쪽 사이에서 잘리지 않게 맞추는 정도입니다.
- 시연 영상은 PDF 안에서 재생되지 않고 **주소 글자**로 보입니다(PDF에서는 누르면 열리지만, 인쇄물에서는 주소를 직접 쳐야 합니다).
- 테마를 바꿔도 포트폴리오 페이지·상세 문서 PDF는 흰 종이로 찍힙니다(강조색만 테마를 따름). 슬라이드 PDF는 화면 색 그대로입니다.

## 슬라이드를 PPTX로 저장하기

| | |
|---|---|
| **방법** | 슬라이드 아래 띠의 **[PPTX로 저장]** 버튼 · 명령 없음 |
| **언제 쓰나** | 면접 발표 자료를 PowerPoint에서 직접 다듬고 싶을 때 |
| **바뀌는 것** | 내려받은 `.pptx` 파일 (레포는 바뀌지 않습니다) |
| **되돌리기** | PPTX에서 고친 내용은 웹 페이지로 돌아오지 않습니다. 다시 누르면 새 파일이 만들어집니다 |

누르면 지금 슬라이드가 PowerPoint 파일(`<프로젝트 제목> - 슬라이드.pptx`)로 내려받아집니다.
면접 발표 자료를 PowerPoint에서 직접 다듬고 싶을 때 씁니다. 화면에 그려진 모습을 그대로 재서 옮기므로 PDF와 같은 장면·같은 배치이고, 요소 하나하나를 PowerPoint에서 고칠 수 있습니다.

- 슬라이드는 16:9 와이드(13.33 × 7.5인치)이고, 장면 1개 = PowerPoint 슬라이드 1장입니다. 쪽 번호는 PDF와 같습니다.
- 누르면 아래 띠에 `PPTX 만드는 중… 12/30`처럼 진행이 보입니다. 처음 한 번은 변환 도구(PptxGenJS)를 인터넷에서 받고, 그림이 많으면 파일로 묶는 데 몇십 초 걸릴 수 있습니다.
- Windows PC의 Chrome · Edge에서 만들기를 권합니다. 휴대폰처럼 좁은 화면에서는 버튼이 숨습니다.
- **PPTX에서 고친 내용은 웹 페이지로 돌아오지 않습니다.** 사실 · 설명이 틀렸으면 프로젝트 문서를 고치고 다시 빌드한 뒤 새로 저장하세요. 장면 배치는 `/portfolio-edit`로 고쳐 두면 다음에 저장할 때도 그대로입니다.
- 반대로 **내가 만든 발표 자료(.pptx)를 재료로 가져오려면** → [발표 자료(PPTX)에서 가져오기](intake.md#발표-자료pptx에서-가져오기)

### 슬라이드의 무엇이 PowerPoint의 무엇이 되나

| 슬라이드에서 | PowerPoint에서 |
|---|---|
| 제목 · 설명 · 카드의 글 | 글상자 (글꼴 · 크기 · 색 · 굵기 · 자간 · 줄 간격 그대로) |
| 카드 · 칩 · 번호 원 | 도형 (둥근 모서리 · 테두리). 글만 든 칩은 도형 안에 글 |
| 표 | PowerPoint 표 (칸 너비 · 채움 · 테두리 · 안쪽 여백 그대로) |
| 코드 | 고정폭 글상자 (구문 강조 색 그대로, 한 줄 = 한 단락) |
| 스크린샷 · GIF | 원본 그림 (GIF는 PowerPoint에서도 움직임) |
| 다이어그램(mermaid) | SVG 그림. PowerPoint 2019 이상 · Microsoft 365에서 오른쪽 클릭 → <b>[도형으로 변환]</b>하면 상자 · 화살표 · 글자를 하나씩 고칠 수 있음 |
| 그러데이션 배경 · 번호 배지 | 그림 (장면 배경은 슬라이드 배경) |
| 목차 · 장 표지의 항목 | 그 슬라이드로 가는 링크 |

### 알아 둘 것

- **글꼴**: 화면과 같은 글꼴 이름(Pretendard · D2Coding · Montserrat, 테마를 바꿨다면 그 글꼴)으로 들어갑니다. 그 글꼴이 PC에 없으면 PowerPoint가 다른 글꼴로 바꿔 보여 줘 **줄바꿈이 조금 달라질 수 있습니다**. [Pretendard](https://github.com/orioncactus/pretendard) · [D2Coding](https://github.com/naver/d2codingfont)을 설치하거나, PowerPoint의 <b>[홈 → 바꾸기 → 글꼴 바꾸기]</b>로 한 번에 바꾸세요.
- **파일 크기**: 움직이는 GIF는 원본 그대로 들어가서 파일이 수십 MB가 될 수 있습니다(샘플 슬라이드 7~32MB).
- **옮기지 않는 것**: 그림자 · 흐림 같은 효과, 그러데이션 글자(첫 색 한 가지로 칠함), 영상.
- **링크**: 다른 페이지로 가는 링크는 만든 곳의 주소로 들어갑니다. 미리보기에서 만들면 `localhost` 주소이니, 남에게 줄 파일은 **배포된 주소**에서 만드세요.
