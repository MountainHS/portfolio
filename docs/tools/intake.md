# 재료 모으기

| | |
|---|---|
| **명령** | `/portfolio-intake <레포 주소 \| 폴더 \| 발표.pptx> [폴더 이름] [--branch 이름] [--update]` · ✋ **직접 입력할 때만** |
| **언제 쓰나** | 프로젝트 문서가 아직 없을 때. 문서를 쓰기 전에 코드와 발표 자료에서 재료부터 뽑습니다 |
| **바뀌는 것** | `src/<번호-이름>/code/`·`_intake/`, `report-intake.md`. `_intake/`와 `report-intake.md`는 git에 올라가지 않습니다(내 PC에만). |
| **되돌리기** | `src/<번호-이름>/_intake/`와 `code/`에서 이 명령이 넣은 파일을 지우면 됩니다. `프로젝트문서.md`와 `images/`는 이 명령이 건드리지 않습니다 |

프로젝트 문서가 아직 없을 때 프로젝트 문서의 **재료**부터 뽑습니다. 재료는 **GitHub 레포**와 **발표 자료(PPTX)** 두 곳에서 가져올 수 있고, 같은 폴더로 둘 다 뽑아도 됩니다(순서는 상관없고, 서로의 재료를 지우지 않습니다).

- **프로젝트 문서는 만들어 주지 않습니다.** 재료의 질문에 답하며 `프로젝트문서.md`를 직접 쓰세요. "질문에 대신 답해 줘"는 거절합니다.

## GitHub 레포에서 가져오기

```text
/portfolio-intake https://github.com/내아이디/내레포
```

코드와 커밋 기록으로 확인되는 사실과 여러분만 답할 수 있는 질문을 `_intake/재료집.md`에, 찍을 화면을 `_intake/촬영목록.md`에, 핵심 `.cs` 사본을 `code/`에 둡니다.

### 레포에서 뽑을 때

- Claude가 레포를 잠깐 받아 **코드와 커밋 기록으로 확인되는 사실**(Unity 버전·패키지·클래스 구조·커밋 기간·버그 수정 후보)과
  **여러분만 답할 수 있는 질문**(왜 이렇게 만들었는지, 무엇을 고민했는지)을 정리합니다. 처음에 폴더 이름 제안과 몇 가지 질문(개인/팀, 외부에서 가져온 코드, 시연 영상)을 한 번에 묻습니다.

  | 파일 | 내용 |
  |---|---|
  | `src/<번호-이름>/code/` | 핵심 `.cs` 사본(원본 그대로 복사) |
  | `src/<번호-이름>/_intake/재료집.md` | ✅ 사실(근거 `파일:줄`·커밋) · ❓ 질문 · ⚠ 추정, 다이어그램 후보(코드에서 본 신호 → 맞는 종류)와 초안 |
  | `src/<번호-이름>/_intake/촬영목록.md` | 찍어야 할 화면·GIF 목록 |
  | `report-intake.md` (레포 맨 위) | 비밀값 의심 위치, 뺀 파일과 이유, 확인할 것 |

- 재료집의 질문에 답하며 `프로젝트문서.md`를 직접 쓰고, 촬영목록대로 찍은 그림을 `images/`에 넣으세요.
- 비밀값(API 키 등)이 의심되는 파일은 복사하지 않고 `report-intake.md`에 위치만 알려 줍니다. 팀 프로젝트는 내가 커밋한 코드 위주로 고르고, 팀원 코드가 섞인 파일은 올려도 되는지 먼저 묻습니다.
- 비공개 레포는 "로그인해서 받아 줘"라고 하면 뜨는 브라우저 창에서 직접 로그인하거나, 레포를 직접 clone·ZIP으로 받아 **그 폴더 경로**를 주면 됩니다.
- 그 밖의 옵션: 폴더 이름 직접 지정(`/portfolio-intake <주소> 3-my-rpg`), 브랜치 지정(`--branch dev`), 다시 뽑기(`--update` — `code/`의 이 명령이 넣은 파일과 `_intake/`의 재료집·촬영목록만 새로 씀. `프로젝트문서.md`·`images/`는 절대 건드리지 않음).

## 발표 자료(PPTX)에서 가져오기

```text
/portfolio-intake "C:\Users\나\Downloads\내 게임 발표.pptx"
```

수업·기획·팀 발표 때 만든 PowerPoint 파일(.pptx)을 재료로 가져옵니다. 슬라이드의 [\[PPTX로 저장\]](export.md#슬라이드를-pptx로-저장하기)과는 반대 방향입니다(내 발표 자료 → 프로젝트 문서 재료).

- 슬라이드마다 **글·표·차트 값·SmartArt·발표자 노트·링크**를 그대로 `src/<번호-이름>/_intake/발표자료.md`에 옮기고, **그림**은 `_intake/pptx/`에 꺼냅니다. 끝에 프로젝트 문서 5단 구조의 질문이 붙습니다.
- PowerPoint가 설치되어 있지 않아도 되고, Python만 있으면 됩니다. `.ppt`(옛 형식)·Keynote·Google 프레젠테이션은 먼저 `.pptx`로 저장해 주세요.
- 꺼낸 그림은 배포되지 않습니다. **쓸 그림만 골라 `images/`로 복사**하세요 — 레퍼런스 게임 화면·로고·인터넷 그림·팀원이 만든 그림은 넣지 않습니다.

### 더 알아 둘 것

- 레포 재료를 이미 뽑은 폴더를 고르면 같은 `_intake/`에 더해집니다(`재료집.md`·`code/`·`프로젝트문서.md`·`images/`는 건드리지 않음).
- 이메일·전화번호로 보이는 글은 가려지고, 파일 이름·작성자 정보는 옮기지 않습니다.
- 옮기지 않는 것: 위치·색·글꼴·애니메이션, 그림 속 글자(글자 인식은 하지 않음), 파일로 들어간 영상(시연 영상은 YouTube 링크로).

## 코드에 없는 재료

재료집은 **코드와 커밋에서 확인되는 것만** 담습니다. 고민과 선택, AI와 일한 방식, 회고, 플레이 화면은 다른 자료가 필요합니다.

- 기획서·회의록·AI 대화 기록·플레이테스트 메모가 있으면 `src/<번호-이름>/_intake/자료/`에 넣어 둡니다(git에 올라가지 않습니다).
- 칸마다 어떤 자료가 필요한지는 [format/07-materials.md](../../format/07-materials.md)에, 지금 무엇이 모자란지는 `/portfolio-check`의 [재료 점검표](check.md#재료-점검표)에 있습니다.
- 재료집의 질문에 답했으면 `- [ ]`를 `- [x]`로 바꿔 두세요. 점검이 남은 질문을 세어 줍니다.
